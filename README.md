## Pacho — Asistente personal de Silvana

Actualmente este repositorio aloja el setup de **Pacho**, un asistente personal
construido sobre Claude Code en la web, conectado a GitHub y a las herramientas
del día a día de Silvana.

Todo está en la carpeta [`Pacho/`](Pacho/):

- [`Pacho/README.md`](Pacho/README.md) — índice y orden recomendado.
- [`Pacho/01_Requerimientos_Setup_Pacho.md`](Pacho/01_Requerimientos_Setup_Pacho.md) — documento de requerimientos y pasos de instalación.
- [`Pacho/02_Preguntas_para_Silvana.md`](Pacho/02_Preguntas_para_Silvana.md) — cuestionario para diseñar a Pacho a la medida de Silvana.
